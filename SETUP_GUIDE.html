Naqeebs Multi Services (NMS) - Setup Guide

Project Name: NMS Accounting SaaS

Base Currency: PKR

Default Login: admin / password

1. Preparation

  1. Copy the NMS folder to your XAMPP directory: C:\xampp\htdocs\NMS.
  2. Place your logo as nms_logo.png in the root NMS folder.

2. Database Setup

  1. Start XAMPP Control Panel and run Apache and MySQL.
  2. Go to http://localhost/phpmyadmin.
  3. Create a new database named: nms_accounting.

3. SQL Import Sequence

Import these 11 files in the sql/ folder in this exact order:

  1. schema.sql
  2. auth.sql
  3. inventory.sql
  4. audit_trail.sql
  5. budgeting.sql
  6. reconciliation.sql
  7. multi_currency.sql
  8. recurring_invoices.sql
  9. pakistan_tax_updates.sql
  10. fix_schema_inconsistencies.sql
  11. nms_custom_setup.sql (Contains your specific Chart of Accounts)

4. Accessing the System

Open your browser and visit: http://localhost/NMS/login.php

  • Username: admin
  • Password: password

5. NMS Chart of Accounts Reference

Type Key Codes
Assets A001 (Cash), A002 (Petty Cash), A003 (Sulaman HBL), A004 (Khakan Bank)
Expenses E001 to E035 (Detailed Operations)
Liabilities L002 (Abdullah Khan Safi), L003 (Danish Munir)
